魔方公式库安卓App产品需求文档（PRD）

一、项目概述

1.1 项目定位

单用户专属魔方公式数据库APP，面向三阶魔方 CFOP 学习者，提供模块/状态集/状态/公式的全生命周期管理、可视化展示、自定义配置、数据本地持久化存储、数据导入导出功能。

1.2 核心特性

- 单用户无登录：直接使用，数据自动保存至APP，关闭/重开应用不丢失

- 内置+自定义双模式：内置 F2L/OLL/PLL 模块，支持无限自定义模块/状态集

- 数据唯一共享：状态实体唯一，可跨状态集共享，不重复存储

- 可视化公式：字母公式自动映射为图形公式，图形素材完全自定义

- 完善操作：拖动手柄排序、长按多选、批量操作、双重校验、移除/删除双逻辑

- 数据互通：支持数据导出、导入备份恢复

1.3 功能架构

二、核心功能完整需求

2.1 全局规则（强制）

- 单用户机制：无账号、无登录，系统默认唯一用户，所有数据归属该用户

- 数据持久化：所有操作实时同步后端，关闭重开数据完全保留

- 唯一性校验：同一层级名称不可重复（模块名/状态集名/状态名）；同一状态集内不可重复添加同一状态

- 删除逻辑：移除（仅从当前状态集删除，状态实体保留，全部状态可见）；删除（删除实体，从所有状态集中彻底清除）

- 交互统一：长按 = 进入多选模式；拖动手柄 = 排序（实时保存）；所有操作成功/失败弹出轻提示；删除类操作必须二次确认

2.2 首页 — 模块管理

2.2.1 内置模块

固定展示 3 个不可删除模块：F2L / OLL / PLL；可编辑名称、描述，不可删除。

2.2.2 自定义模块

- 支持：添加 / 编辑 / 删除 / 拖动排序

- 添加/编辑校验：模块名称不可重复，重复则弹出提示，不执行操作

- 删除逻辑（核心修改）：
        

  - 删除行为：删除自定义模块时，会级联删除该模块下的所有数据（该模块下所有状态集、所有状态集里的所有状态、所有状态里的所有公式、所有关联关系数据）

  - 强制二次确认弹窗：标题（警告）；内容（删除模块将同时删除该模块下所有状态集、状态、公式，数据不可恢复，确定删除？）；按钮（取消 / 确认删除）

  - 只有点击“确认删除”才执行删除操作

2.2.3 底部导航

固定：首页、设置 两项。

2.3 模块页 — 状态集管理

2.3.1 内置状态集

每个模块自带一个【全部状态】（不可删除），展示该模块下所有状态实体。

2.3.2 自定义状态集

- 支持：添加 / 编辑 / 删除 / 拖动排序

- 名称唯一校验

- 删除逻辑：删除自定义状态集时，仅删除该状态集本身 + 关联关系；不删除状态实体、不删除公式；二次确认弹窗（内容：确定删除该状态集？仅删除集合，不删除状态和公式）

2.4 状态集页 — 状态列表

2.4.1 通用能力

- 状态展示：状态图例 + 状态名 + 状态描述 + 公式数量

- 拖动排序：当前集内独立排序，互不影响

- 长按进入多选模式：批量选择状态；按钮（添加到其他状态集、删除）

- 单个状态操作按钮：添加到（选择目标集，已存在则提示不添加）；编辑（修改名称、图例、描述）；操作（移除 / 删除，二选一）

2.4.2 【全部状态】特殊规则

状态操作仅允许删除，不允许移除；删除 = 彻底销毁状态实体，全量移除。

2.4.3 自定义状态集规则

支持移除（仅移出当前集）；支持删除（彻底销毁）。

2.5 状态详情页 — 公式管理

2.5.1 状态信息

- 状态图例：仅支持用户上传，无系统默认图

- 状态名、描述可编辑

- 操作按钮同 2.4.1

2.5.2 公式管理（核心）

- 支持多条公式，可拖动排序

- 每条公式包含：字母公式（仅允许指定字符）；图形公式（自动根据字母映射图片拼接，不显示括号）；起手（上起手 / 中起手 / 下起手，单选）；备注（自定义文本）；操作（编辑 / 删除）

- 公式编辑支持两种输入方式：直接键盘输入；点击按钮输入（系统提供全字母按钮）；辅助按钮（退格、左括号、右括号）

- 公式格式化功能：点击确认按钮后，系统自动对输入的公式进行格式化处理，具体规则如下：
              每个相邻字母（含字母组合，如R'、L2）之间插入一个空格；

- 公式首位、末尾必须为字母（或字母组合），自动去除首尾多余空格；

- 括号与字母（或字母组合）之间不插入空格；

- 括号与括号之间不插入空格。

- 允许的公式字符（强制校验）：
        
R R' R2 L L' L2 U U' U2 D D' D2 F F' F2 B B' B2
        
x x' x2 y y' y2 z z' z2
        
M M' M2 E E' E2 S S' S2
        
r r' r2 l l' l2 u u' u2 d d' d2 f f' f2 b b' b2
        
( )
      

2.6 设置页

2.6.1 字母图片映射

- 展示全部公式字母列表

- 每个字母支持：上传自定义图片、预览图片、删除图片

- 修改后所有公式图形版自动同步更新

2.6.2 数据导入 / 导出

- 导出：按钮（导出全部数据）；内容（模块、状态集、状态、公式、字母映射、图片）；行为（app提示配置文件导出到路径）

- 导入：按钮（选择文件导入）；逻辑（覆盖当前全部数据）；二次确认（警告 + 确认）；导入成功自动刷新页面

2.7 后端与数据规则（最终）

- 单用户数据表结构（无用户表，默认绑定唯一用户）

- 所有数据实时保存app后端

- 状态与状态集为多对多关系（一个状态可属于多个集）

- 状态实体唯一存储，共享使用

- 图片上传至app后端
