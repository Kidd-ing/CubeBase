魔方公式库 Android App 技术设计文档
（纯文本可复制版，无复杂格式、无外链，全成熟组件・纯本地运行）

一、总体技术方案
1.1 项目定位
纯本地离线单用户应用，无云端服务、无后端接口、无登录、无用户体系。所有数据、逻辑、图片、文件均保存在 Android 设备本地。整体基于 Web 技术栈封装为原生 App，全程使用成熟开源框架与组件，不手写底层逻辑、不重复造轮子。
1.2 核心技术栈（全部成熟稳定组件）
前端框架：Vue 3 + Vite
UI 组件库：Element Plus（移动端适配）
状态管理：Pinia
路由管理：Vue Router 4
本地数据库：Dexie.js（IndexedDB 封装，支持事务、多表、关联查询）
拖拽排序：vuedraggable@next（基于 Sortable.js，支持手柄拖动、长按多选）
本地文件能力：Capacitor Filesystem（Android 本地文件读写、导入导出）
图片处理：browser-image-compression（常规图片压缩，兼容 SVG/GIF 不压缩）、html2canvas（公式图形拼接）
移动容器：Capacitor 6（将 Web 封装为 Android 原生 App）
工具库：uuid、dayjs、lodash-es（深拷贝、去重、对象处理）
1.3 技术架构分层（纯本地分层）
1. UI 展示层：Vue 组件 + Element Plus，负责页面渲染与交互
2. 业务逻辑层：Pinia Store + 工具函数，处理校验、格式化、业务规则
3. 数据持久层：Dexie.js 本地数据库，存储所有结构化数据
4. 原生能力层：Capacitor 插件，提供文件、存储、本地路径能力

二、本地数据库设计（Dexie.js 实现）
2.1 设计原则
• 单用户无用户表，默认归属唯一用户
• 状态实体唯一存储，状态与状态集多对多关联
• 所有增删改操作实时持久化，关闭 App 数据不丢失
• 支持事务、级联删除、数据一致性保证
• 完整支持 PNG/JPG/JPEG/WebP/SVG/GIF 格式图片存储与展示
2.2 数据表结构
1. modules（模块表）
字段：id、name、desc、type（builtIn /custom）、sort、createTime
2. sets（状态集表）
字段：id、moduleId、name、desc、type（builtIn /custom）、sort、createTime
3. states（状态表）
字段：id、name、desc、image（Base64 格式，支持所有图片类型）、imageType、createTime
4. stateSetRel（状态 - 状态集多对多关联表）
字段：id、stateId、setId、sort
5. formulas（公式表）
字段：id、stateId、content、formatted、hand（起手方式）、remark、sort、createTime
6. letterImages（字母图片映射表）
字段：letter、image（Base64 格式，支持所有图片类型）、imageType、updateTime
2.3 初始化内置数据
应用首次启动自动创建：
• 三个内置模块：F2L、OLL、PLL（不可删除）
• 每个模块对应一个内置 “全部状态” 状态集（不可删除）
后续所有自定义模块、状态集、状态、公式均由用户创建并本地保存
2.4 核心数据规则
1. 名称唯一性校验：同一层级名称不可重复，通过数据库查询判断
2. 状态共享机制：状态只存一份，通过关联表归属多个状态集
3. 删除逻辑区分：
• 移除：仅删除关联关系，不删除状态实体
• 删除：彻底删除实体及所有关联数据
4. 级联删除规则：删除自定义模块时，级联删除该模块下所有状态集、状态、公式、关联关系
5. 排序规则：所有列表均存储 sort 字段，拖拽后实时批量更新
6. 图片规则：支持 PNG/JPG/JPEG/WebP/SVG/GIF 格式，统一以 Base64 存储，原生渲染展示

三、核心功能技术实现
3.1 全局通用能力
1. 数据持久化
所有页面数据从 Dexie 读取并同步到 Pinia，所有增删改操作实时写入数据库，页面刷新 / 重启 App 数据自动恢复。
2. 交互统一实现
• 长按进入多选：使用 checkbox 组合实现，由 Pinia 控制批量模式状态
• 拖拽排序：使用 vuedraggable 组件，通过手柄图标触发拖动，结束后批量更新 sort 并保存
• 操作提示：使用 Element Plus 的 ElMessage 轻提示
• 二次确认：使用 ElMessageBox 实现删除、导入覆盖等危险操作确认
3. 全局校验工具
• 模块名 / 状态集名 / 状态名重复校验
• 公式字符合法性校验
• 公式自动格式化处理
• 图片格式校验：支持 PNG/JPG/JPEG/WebP/SVG/GIF
3.2 模块管理（首页）
1. 内置模块 F2L/OLL/PLL
标记 type=builtIn，界面隐藏删除按钮，仅允许编辑名称和描述。
2. 自定义模块
支持新增、编辑、删除、拖拽排序。
删除时执行数据库事务，级联删除该模块下所有状态集、关联关系、状态、公式。
3. 底部导航
固定 “首页”“设置” 两项，使用 Vue Router 切换页面。
3.3 状态集管理（模块页）
1. 内置 “全部状态” 状态集
type=builtIn，不可删除，展示该模块下所有状态。
2. 自定义状态集
支持增删改查、拖拽排序。
删除时仅删除状态集本身与关联关系，不删除状态实体与公式。
3.4 状态列表（状态集页）
1. 状态展示
状态图例（支持 PNG/JPG/SVG/GIF 直接渲染）、名称、描述、公式数量、拖拽手柄。
2. 长按多选
支持批量添加到其他状态集、批量删除。
3. 操作区分
• 在全部状态页：只允许删除，不允许移除
• 在自定义状态集页：支持移除（仅移出当前集）和删除（彻底销毁）
4. 重复添加校验
同一状态不可重复加入同一状态集，添加前查询关联表判断。
3.5 状态详情与公式管理（核心）
1. 状态信息
展示自定义上传的状态图例（支持 PNG/JPG/SVG/GIF 动态渲染），可编辑名称、描述。
2. 多公式管理
支持一个状态对应多条公式，可拖拽排序、编辑、删除。
3. 公式输入与校验
允许字符包括：
R R' R2 L L' L2 U U' U2 D D' D2 F F' F2 B B' B2
x x' x2 y y' y2 z z' z2
M M' M2 E E' E2 S S' S2
r r' r2 l l' l2 u u' u2 d d' d2 f f' f2 b b' b2
以及括号 ( )
通过正则校验非法字符，不符合则不允许保存。
4. 公式格式化规则
• 相邻字母组合之间自动加空格
• 自动去除首尾空格
• 括号与字母之间不加空格
• 首尾必须为合法字符
5. 图形公式生成
根据字母映射图片，按公式字符顺序自动横向拼接展示，修改字母图片后全局自动更新。
6. 起手方式
支持上起手、中起手、下起手单选存储。
3.6 图片管理（纯本地，全格式支持）
1. 支持格式：PNG、JPG、JPEG、WebP、SVG、GIF
2. 状态图例：用户上传图片，SVG/GIF 不压缩直接存储，常规图片自动压缩后转为 Base64 存入数据库
3. 字母图片映射：每个魔方字母可自定义图片，支持所有格式，修改后所有公式图形同步更新
4. 渲染能力：SVG 矢量图无损渲染、GIF 动图自动播放、常规图片正常展示
5. 无默认图片，全部由用户自定义上传
3.7 数据导入导出（纯本地文件，完整包含所有图片资源）
1. 导出功能
一键导出完整数据包，包含：模块、状态集、状态、公式、状态图片（全格式）、字母图片映射（全格式）、所有关联关系。
所有图片以 Base64 格式内嵌到导出文件中，确保导出文件独立完整、无外部依赖，可直接用于备份与迁移。导出文件格式为 JSON，保存到 Android 本地文档目录。
2. 导入功能
选择本地备份 JSON 文件，导入前二次确认，导入流程会完整还原：
所有结构化数据 + 所有状态图片（PNG/JPG/SVG/GIF）+ 所有字母图片映射，覆盖当前全部数据并刷新页面。
导入后图片自动恢复渲染，GIF 正常播放、SVG 无损展示、公式图形渲染完全正常。
所有文件读写与图片解析使用 Capacitor Filesystem 实现，不使用云存储、不依赖网络。

六、开发规范
1. 禁止手写 IndexedDB、文件系统、拖拽排序等底层逻辑，全部使用成熟组件
2. 所有数据操作必须使用 Dexie 事务，保证数据安全
3. 禁止直接操作 DOM，全部使用 Vue 响应式与 Element Plus 组件
4. 图片、文件、数据全部本地存储，不请求任何远程接口
5. 公式校验、格式化、导入导出统一封装工具函数，全局复用
6. 拖拽、排序、批量操作统一使用 vuedraggable 实现
7. 图片上传与展示必须兼容 PNG/JPG/JPEG/WebP/SVG/GIF 格式
8. SVG/GIF 不执行压缩处理，直接以 Base64 存储与渲染

七、部署与运行说明
1. 项目依赖全部通过 npm 安装，无外部私有源
2. 构建后纯本地运行，无需网络、无需登录、无需后端服务
3. 数据完全由用户设备本地保管，卸载 App 数据清除
4. 支持备份导出文件，更换设备可通过导入恢复数据
5. 兼容 Android 8.0 及以上版本
6. 全格式图片在 Android Webview 中自动渲染，无需额外插件

八、优势总结
1. 零造轮子：全部使用主流稳定开源库，开发效率高、Bug 少
2. 纯本地运行：无服务端、无接口、无云存储、无隐私风险
3. 数据安全：IndexedDB 持久化，关闭 App 不丢失
4. 交互流畅：拖拽、批量操作、图片渲染均由成熟库支撑
5. 图片能力强：完整支持 PNG/JPG/SVG/GIF，动图 / 矢量图完美兼容
6. 备份完整：导入导出包含所有图片资源，迁移无忧
易于维护：技术栈统一、结构清晰、无自定义底层代码
