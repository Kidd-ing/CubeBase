魔方公式库 Android App UI 设计文档
（纯文本可复制版，无复杂格式，表格改为段落说明）

一、设计总览
1.1 设计理念
整体采用简洁高效的工具类设计风格，专注魔方 CFOP 学习场景，界面轻量化、层级清晰、操作直观，无冗余视觉干扰。遵循触控优先原则，保证长按、拖拽、批量操作等交互流畅统一。
设计原则：
1. 信息层级严格遵循 模块 → 状态集 → 状态 → 公式 四级结构。
2. 所有可点击区域不小于 48px，按钮间距不小于 16px，避免误触。
3. 全局交互统一：长按进入多选、拖拽手柄排序、操作后轻提示、删除类操作必须二次确认。
4. 视觉轻量化，以卡片、分割线区分内容，突出公式与魔方状态展示。
1.2 推荐技术栈（成熟稳定，适合 Trae 开发）
前端框架：Vue 3 + Vite
UI 组件库：Element Plus 移动端适配版
状态管理：Pinia
本地存储：IndexedDB + LocalForage
路由：Vue Router 4
图片与公式拼接：html2canvas
Android 打包：Capacitor
拖拽排序：vuedraggable

二、全局设计规范
2.1 色彩规范
主色调：#165DFF（品牌蓝，用于导航、主按钮、选中状态）
内置模块区分色：
F2L：#2563EB
OLL：#4F46E5
PLL：#9333EA
中性色：
页面背景：#F5F7FA
卡片背景：#FFFFFF
主文本：#1D2129
次要文本：#4E5969
提示文本：#86909C
分割线 / 边框：#E5E6EB
功能色：
成功提示：#00B42A
警告操作：#FF7D00
错误提示：#F53F3F
危险按钮：#F53F3F
2.2 字体规范
使用 Android 系统无衬线字体（Roboto / 思源黑体）。
页面标题：18px，字重 600
卡片 / 列表标题：16px，字重 500
正文内容：14px，字重 400
辅助说明 / 提示：12px，字重 400
按钮文字：14px，字重 500
2.3 间距与尺寸规范
基础间距单位 4px，常用间距 8px、16px、24px、32px。
卡片圆角：12px
按钮圆角：8px
普通列表项高度：56px
带图片状态项高度：72px
操作图标尺寸：24px
辅助小图标：16px
2.4 交互反馈规范
点击效果：按钮按压变色，列表项点击涟漪效果。
操作提示：全局统一 Toast 轻提示，停留 2 秒，成功 / 警告 / 错误区分颜色。
二次确认：删除、导入覆盖等危险操作使用居中弹窗。
多选模式：长按进入，顶部出现操作栏，卡片显示复选框。
拖拽排序：拖动时条目悬浮高亮，松手后实时保存排序。

三、页面 UI 详细设计
3.1 首页 — 模块管理页
页面结构：
顶部导航栏：高度 56px，背景主色调，左侧显示应用名 “魔方公式库”。
内容区域：垂直卡片列表，上下内边距 24px，卡片间距 16px。
底部导航栏：固定高度 56px，白色背景，包含 “首页”“设置” 两项，选中为蓝色，未选中灰色。
模块卡片内容：
内置模块（F2L、OLL、PLL）：
左侧方形色块图标，颜色对应模块色；
中间显示模块名称 + 简短描述；
右侧箭头图标，点击进入模块页；
不可删除，仅可编辑名称与描述。
自定义模块：
样式与内置模块一致；
卡片右上角显示更多操作图标（编辑 / 删除）；
列表底部有 “+ 新增模块” 虚线按钮。
弹窗说明：
新增 / 编辑模块弹窗：标题 + 模块名称输入框 + 描述输入框 + 取消 / 确定按钮，名称重复则报错。
删除模块警告弹窗：标题 “警告”，内容 “删除模块将同时删除该模块下所有状态集、状态、公式，数据不可恢复，确定删除？”，按钮取消、确认删除。

3.2 模块页 — 状态集管理页
页面结构：
顶部导航：返回箭头 + 当前模块名称 + 右侧 “新建状态集” 按钮。
内容区域：状态集列表，内边距 24px，条目间距 12px。
状态集条目：
内置 “全部状态”：白色卡片，显示名称 + 状态总数，不可删除，点击进入状态列表。
自定义状态集：名称 + 状态数量 + 描述，右侧编辑与删除按钮。
列表底部有 “+ 新增状态集” 虚线按钮。
弹窗说明：
新增 / 编辑状态集：名称输入 + 描述输入，名称唯一校验。
删除状态集弹窗：提示 “确定删除该状态集？仅删除集合，不删除状态和公式”，二次确认。

3.3 状态集页 — 状态列表页
页面结构：
顶部导航：返回箭头 + 状态集名称 + “添加状态” 按钮。
内容区域：状态卡片列表，内边距 16px，卡片间距 12px。
状态卡片内容：
左侧状态图例（方形缩略图）；
中间状态名称、描述；
右侧公式数量标签 + 拖拽排序手柄。
交互规则：
点击卡片进入状态详情页。
长按任意卡片进入多选模式，顶部显示操作栏：全选、添加到其他状态集、删除。
单个状态操作菜单：添加到其他集、编辑、移除 / 删除。
在 “全部状态” 页中，只允许删除，不允许移除；删除即彻底销毁状态。
在自定义状态集中，可选择移除（仅移出当前集）或删除（彻底销毁）。
提示规则：
同一状态重复添加到某状态集时，弹出 Toast 提示 “该状态已存在”。

3.4 状态详情页 — 公式管理页
页面结构：
顶部导航：返回箭头 + 状态名称 + 编辑状态信息按钮。
内容分为两部分：
1. 状态信息区
居中展示状态图例（80px 左右）；
下方显示状态名称、描述；
底部提供状态操作按钮（添加到其他集、编辑、移除 / 删除）。
2. 公式列表区
标题 “公式列表”+ 右侧 “添加公式” 按钮。
公式卡片内容：
上部：格式化后的字母公式；
中部：自动拼接生成的图形公式（无括号）；
下部：起手标签（上 / 中 / 下起手）+ 备注内容；
右侧：拖拽手柄、编辑按钮、删除按钮。
公式编辑弹窗（核心）：
弹窗内包含：
公式输入框（支持键盘输入）；
快速输入按钮面板：所有允许字符按钮 + 退格 + 括号；
起手方式单选组；
备注输入框；
取消 / 确定按钮。
公式格式化与校验规则：
仅允许字符：R R' R2 L L' L2 U U' U2 D D' D2 F F' F2 B B' B2、x x' x2 y y' y2 z z' z2、M M' M2 E E' E2 S S' S2、r r' r2 l l' l2 u u' u2 d d' d2 f f' f2 b b' b2 以及括号。
格式化规则：
相邻字符间加空格；
自动去除首尾空格；
括号与字符 / 括号之间不加空格；
首尾必须为合法字符。

3.5 设置页
页面结构：
顶部标题 “设置”；
内容为分组列表，分为两大块：字母图片映射、数据导入导出。
1. 字母图片映射区域
标题 “公式字母映射”，下方提示 “修改后所有公式图形自动同步”。
以网格形式展示所有允许字母，每个字母项显示字母 + 当前映射图片，无图片则显示占位图标。
点击字母弹出操作：上传图片、预览图片、删除图片。
2. 数据导入导出区域
导出全部数据：点击后执行导出，Toast 提示导出路径与结果。
导入数据：点击弹出警告弹窗 “导入将覆盖全部数据，不可恢复”，选择文件后覆盖现有数据并刷新页面。

四、复用组件说明
1. 模块卡片组件：用于首页展示模块，支持点击、编辑、删除、拖拽排序。
2. 状态集列表组件：用于模块页，统一展示名称、数量、操作按钮。
3. 状态卡片组件：用于状态集页，支持图例、多选、拖拽、菜单操作。
4. 公式卡片组件：用于状态详情页，展示字母公式、图形公式、起手、备注。
5. 通用弹窗组件：统一新增、编辑、确认删除弹窗样式。
6. 全局 Toast 组件：所有操作反馈统一调用。
7. 公式输入键盘组件：复用在公式编辑弹窗，提供快速字符输入。

五、开发与适配说明
1. 所有数据本地持久化，关闭 APP 不丢失，无登录、无用户表。
2. 状态与状态集多对多存储，状态实体唯一共享，不重复存储。
3. 自定义字母图片保存至本地，修改后全局公式图形自动刷新。
4. 导入导出文件为 JSON 格式，包含模块、状态集、状态、公式、字母映射、图片资源。
5. 拖拽排序使用 vuedraggable 实现，排序结果实时保存到本地数据库。
6. Android 端文件读写使用 Capacitor 原生能力，保证导入导出稳定可用。
